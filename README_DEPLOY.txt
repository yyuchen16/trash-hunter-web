Trash Hunter - Stable Web Version

This folder is the HTML5 Canvas + JavaScript web version.
It connects to Supabase REST for login, registration, online scores, and rankings. If score writing is blocked, the game falls back to a local browser leaderboard for score display.

How to test on this computer:
1. Open http://127.0.0.1:8770/ while the local server is running.

How to let everyone open it:
1. Upload this whole folder to a static web host, such as Netlify, GitHub Pages, Vercel, or a school web server.
2. The uploaded folder must include index.html, style.css, game.js, assets, and music.
3. Share the hosted https URL, not 127.0.0.1.

Important:
127.0.0.1 only works on your own computer. Other people need the hosted website URL.
